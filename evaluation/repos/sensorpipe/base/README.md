# sensorpipe

Industrial sensor data pipeline library: CSV/JSON ingestion of readings, engineering unit conversion,
calibration curves, numpy-based resampling and windowed statistics, anomaly detection, a device registry
with firmware gating, YAML pipeline configuration, a local SQLite store-and-forward buffer and report export.

Run the tests with `python -m pytest`.
